# Logos

- medemax.png: imagem 1 fornecida, logo do projeto MedeMax.
- grupo_maxwell.png: imagem 2 fornecida, logo do Grupo Maxwell.
- logosatc.png: opcional, não fornecida. Coloque aqui para exibir o logo da instituição na seção Sobre.

As imagens são exibidas com proporção preservada. Os originais foram copiados sem edição. A imagem opcional é carregada ao abrir o programa. No EXE, também pode ser colocada diretamente ao lado do executável ou na subpasta assets ao lado dele.

- qtbase_pt_BR.qm: catálogo oficial de português brasileiro distribuído com PySide6/Qt 6.11.2. Usado nos botões, diálogos e menus padrão. Incluído como recurso no EXE pelo comando de build existente.
